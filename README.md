One line a gamer texts the boss to skip work during GTA 6 launch week — an excuse a tired manager would almost believe. No drama, no over-explaining, just a sick little sister, a mum on shift, and a morning that fell apart before it started.

> Boss, my sister's school called, she's got a fever and mum's on shift, I'm stuck at home with her

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (one line, 97 characters, 19 words — inside the 140-character / 20-word limits), with mode 644 so the grader can read it.
